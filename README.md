# PA5X Set Tool

Програма за Windows за KORG PA5X сетове (KST): преглед на стилове, Keyboard Sets и Pads,
прослушване, копиране на вариации и писти между стилове и експорт към MIDI.

Независим проект, не е свързан с KORG.

## Обновления

Програмата сама проверява папката `updates/` в това хранилище при стартиране.
`updates/manifest.json` описва последната версия; файловете ѝ са в `updates/<версия>/`
и се проверяват по SHA-256 преди инсталиране.
